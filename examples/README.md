# 示例培训逐字稿

这个目录包含示例培训逐字稿，用于测试和演示知识卡片生成器。

## 可用示例

### sample_training.txt
**主题**: 产品经理敏捷开发实战培训

**内容概述**:
- 敏捷开发基本概念
- 用户故事和 INVEST 原则
- Sprint 计划和执行
- 敏捷实践（每日站会、看板、评审会议等）
- 技术债务管理
- 敏捷转型挑战

**使用方法**:
```bash
python main.py --input examples/sample_training.txt
```

## 添加自己的培训内容

你可以将自己的培训逐字稿放在这个目录下，支持以下格式：
- `.txt` - 纯文本文件
- `.md` - Markdown 文件

### 建议的逐字稿格式

```
培训标题

培训内容正文...

（可以包含多个段落，涵盖不同的知识点）
```

### 最佳实践

1. **内容结构清晰**: 按照逻辑顺序组织内容
2. **包含具体示例**: 具体的案例和示例能帮助 AI 更好地理解
3. **适当的长度**: 建议 2000-10000 字，太短可能提取不出足够的知识点，太长可能超过 API 限制
4. **语言清晰**: 使用清晰、专业的语言

## 输出示例

运行示例后，会在 `output/` 目录生成：
- `overview.md` - 知识总览（包含思维导图）
- `cards/card_01.md` ~ `cards/card_0X.md` - 多张知识卡片
